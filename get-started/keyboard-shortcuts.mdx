---
title: "Keyboard Shortcuts"
description: "Reference common keyboard shortcuts for editing, navigation, driver management, search, and context menus in Runway."
---

Use `Cmd` on Mac or `Ctrl` on Windows.

### **Editing and navigation**

- `Enter`: Edit cell or save (if already editing)
- `Shift` + `Enter`: Open plan picker
- `Cmd` + `Enter`: Toggle drill-in in driver tables
- `Cmd` + `Option` + `Enter`: Collapse this level of drill-in in driver tables
- `Shift` + `Select` or `Arrow`: Select drivers or data cells
- `Option` + `Shift` + `A`: Hide or show the **Actual Formula** column
- `Option` + `Shift` + `F`: Hide or show the **Forecast Formula** column

### **Copy, paste, and undo/redo**

- `Cmd` + `C`: Copy
- `Cmd` + `V`: Paste
  - Drivers and data values can both be pasted, but must be done separately.
  - To paste into an empty group, select an existing driver first, then use `Cmd` + `V` to paste below.
- `Cmd` + `Z`: Undo
- `Cmd` + `Shift` + `Z`: Redo

### **Driver management**

- `Backspace`: Remove driver from block (non-destructive)
- `Shift` + `Backspace`: Delete driver entirely (destructive)
- `Cmd` + `G`: Group selected drivers
- `Cmd` + `D`: Duplicate a driver
- `Cmd` + `Shift` + `Enter`: Open selected driver’s detail view
- `Cmd` + `Option` + `=`: Add a driver above the current selection
- `Cmd` + `Option` + `-`: Add a driver below the current selection
- `Cmd` + `Shift` + `B`: Add selected drill-in drivers to block
- `Cmd` + `Option` + `Enter`: Collapse parent drill-in from a striped input line

### **Search, context menu, and add**

- `Cmd` + `K`: Search
- `Cmd` + `/`: Open the context menu directly in a driver grid
- `/`: Add a block on a page
