You can add people from workspace settings or from the **Share** sheet on a resource. Use [Permissions](/guides/sharing/permissions) as the canonical guide for which roles and access levels to choose.

<Warning>
  Runway does **not** send email invites when you add users. After adding someone, share your org’s URL—or a direct link to a specific page—to help them get started. When they visit the link, they’ll be prompted to log in and then routed to the content they’ve been granted access to.
</Warning>

## Adding users via settings

Use this method when adding workspace users:

1. Click your avatar in the top-right corner and select **Settings.**

   ![Settings](/images/adding-users/settings.png)
2. Go to the **Users** tab.

   ![Settings Users](/images/adding-users/settings-users.png)
3. Enter one or more email addresses (comma- or space-separated).
4. Assign a role: Admin, Manager, Member, or Guest.

   ![Settings Users Emails](/images/adding-users/settings-users-emails.png)
5. Click **Add.**

<Warning>
  Role and resource access are separate. Before assigning a role, review [Permissions](/guides/sharing/permissions) and [Roles and access](/reference/roles-and-access).
</Warning>

## Adding users via share menu

This method is best when you want to grant access to a specific resource while adding the user.

Users added for the first time through the Share menu can be managed later from **Settings**.

### Step 1: Add user emails

1. Open the page, model, or database you want to share.
2. Click **Share** in the top-right corner.
3. Enter one or more email addresses.
   - If the user is already in your organization, their name will appear in the dropdown.
   - If not, you’ll be prompted to add them.
   - You can also paste multiple emails, separated by commas or spaces.

![Page Share](/images/adding-users/page-share.png)

### Step 2: Set the appropriate access level

Once added, choose the user's [access level](/guides/sharing/permissions#access-levels) for the shared page, model, or database. The available levels depend on the resource type and the user's role.

![Page Share Access Level](/images/adding-users/page-share-access-level.png)

### Step 3: Manage scenario access

Scenario access can be managed from the shared resource when you need to control which scenarios are visible there.

To manage this:

1. Navigate to the scenario access tab on the shared page, model, or database.
2. Select which scenarios should be visible from that resource.

<Info>
  Scenario access follows the sharing settings for that resource. See [Permissions](/guides/sharing/permissions) for the current access model.
</Info>

![Page Share Guests Scenarios](/images/adding-users/page-share-guests-scenarios.png)

## Using a Guest invite link

For easier bulk access, you can enable a **Guest invite link**. Anyone with this link can access the shared resource according to the link settings.

If someone uses the link and has not been added to Runway before, they appear in your user list.

The link grants access to the specific page, model, or database it was generated from. You can disable it at any time from the Share menu.

![Page Share Guest Link](/images/adding-users/page-share-guest-link.png)

## Managing users

Users with user-management access can manage users and review roles and access levels from **Settings** > **Users**.

For each user, you’ll see:

- Their **current role** — click to update it.
- The number of pages, models, and databases they have access to — click to view the full list and update access levels as needed.

![Modify Users](/images/adding-users/modify-users.png)

You can tell whether someone has accessed Runway by checking their avatar. Users who haven’t logged in yet won’t have a profile photo.

![Settings Users No Avatar](/images/adding-users/settings-users-no-avatar.png)

Learn more about the different [roles](/guides/sharing/permissions#user-roles) and [access levels](/guides/sharing/permissions#access-levels) in their respective articles.
